Personal Project · 2026 · Cairo

NEXUS — Multilingual RAG & NER Intelligence System

LangChainQdrantGemma4 12BQwen3 EmbedGLiNERAraBERTLM StudioRe-ranking
GitHub (add link)
Situation

Industrial document corpora in the Arab world are inherently mixed-language — the same entity appears as "Al Noor Cement", "Al-Noor Cement Co.", "شركة النور للاسمنت" across the same set. Standard RAG pipelines fail: they can't resolve aliases across scripts, miss Arabic morphology, and hallucinate when retrieval doesn't distinguish person from organization from legal entity.

Task

Build a production-grade multilingual RAG system from scratch — indexing thousands of Arabic and English documents, resolving entity aliases across both scripts, extracting typed entities with high precision, serving grounded answers with source citations — all running locally, no cloud.

Action

Architected in LangChain — ingesting PDF, TXT, MD documents, chunking with overlap-aware strategies, embedding via Qwen3 Embed served via LM Studio, stored in Qdrant. Added a re-ranker before generation to sharpen cross-language retrieval precision.

Built a dual-NER pipeline: GLiNER handles English and European documents — extracting persons, organizations, facilities, legal entities, contacts, and IDs. AraBERT (trained on 80 GB Arabic data) handles Arabic — resolving name suffixes, script variants, and morphological forms. LLM layer runs Gemma4 12B via LM Studio — no API calls, no data leaving the machine.

Result

Indexed 61,351 vectors across 2,912 files. Stress-tested on 3,000 files fully locally. Ask in English, get answers from Arabic sources. Ask for a field not in the documents — the system cites the source confirming absence. No hallucination. Grounded refusal with evidence.

Academic Project · McMaster · 2024

Student ID Seven-Segment Display

Digital LogicK-mapsNAND-only DesignCircuit SimulationBreadboard
GitHub (add link)

Live demo — breadboard

Situation

Display every digit of a student ID in sequence on a single seven-segment display — no microcontroller, no code. Pure combinational logic from discrete gates on a breadboard.

Task

Derive truth tables for each digit's segment encoding, minimize using K-maps, implement exclusively with NAND gates to minimize transistor count, simulate before hardware, then build and verify on a physical breadboard.

Action

Derived Boolean expressions for all seven segments across each digit. Applied K-map minimization. Converted to NAND-only form via De Morgan's law — NAND gates use fewer transistors and are the standard cell in CMOS. Simulated in an online circuit simulator to verify before hardware. Built on a breadboard with physical ICs and verified each digit sequencing correctly.

Result

A working physical circuit sequencing every student ID digit — designed, simulated, and built end-to-end using only combinational logic. Demonstrates Boolean algebra, K-map minimization, NAND universality, and the simulation-to-hardware workflow.

Academic Project · McMaster · 2025

Ball-and-Beam PID Control System

MATLABSimulinkQUARCNI myRIOPID / PD ControlRoot Locus
GitHub (add link)
Situation

The ball-and-beam is a classic unstable control problem — without active feedback the ball rolls off. The challenge: model the nonlinear electromechanical dynamics accurately enough that a linear controller works on real hardware.

Task

Derive the plant transfer function, design PD and PID controllers using root-locus, implement in Simulink with QUARC, and validate on a physical NI myRIO-controlled rig.

Action

Modeled the full electromechanical dynamics. Derived the open-loop transfer function and plotted root locus to identify stable controller regions. Designed a PD controller for fast settling then added integral action to eliminate steady-state error. Deployed via QUARC real-time target on NI myRIO and measured step response, disturbance rejection, and parameter sensitivity.

Result

Achieved stable ball positioning with controlled settling time and minimal overshoot on physical hardware — validating the full design loop from mathematical model to real-time embedded controller.
